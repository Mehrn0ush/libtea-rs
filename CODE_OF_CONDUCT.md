# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository (issues, pull requests, discussions, reviews) and
wherever someone represents the project.

## Reporting

Report unacceptable behavior privately to the maintainer,
[@Mehrn0ush](https://github.com/Mehrn0ush), at the email address on that GitHub
profile. Do not report it in a public issue. Reports are read by the maintainer
only and are kept confidential.

You will get an acknowledgement within 14 days. The maintainer decides on the
response, following the Covenant's enforcement guidelines (correction, warning,
temporary ban, permanent ban), and tells the person who reported what was done.

Security vulnerabilities are not conduct reports: report them as described in
[SECURITY.md](SECURITY.md).
